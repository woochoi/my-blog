오늘의 수업

모두의연구소 아이펠에서
Git & GitHub 입문

개발자라면 매일 쓰는 도구라는데, 드디어 제대로 배워봤다.

"왜 쓰는지"부터 알고 나니 훨씬 재미있었다.

03
🕰️

Git이란?

파일의 변경 기록을
저장하는 타임머신

최종.txt, 진짜최종.txt, 진짜진짜최종.txt는 이제 안녕.

Git은 언제, 무엇을, 왜 바꿨는지 기록하고 원할 때 그 시점으로 돌아갈 수 있게 해준다.

04
🔁

Git의 기본 흐름

수정하고, 담고,
기록한다

작업 폴더→ git add→ git commit→ git push

add로 저장할 파일을 고르고, commit으로 기록을 남기고, push로 GitHub에 올린다.

05

오늘 써본 명령어

이것만 알아도 시작할 수 있다

  • git init폴더를 Git 저장소로
  • git status지금 상태 확인
  • git add .변경 사항 담기
  • git commit -m기록 남기기
  • git remote addGitHub 저장소 연결
  • git pushGitHub에 올리기
06
🐙

Git vs GitHub

이름은 비슷해도
역할은 다르다

Git내 컴퓨터에서 버전을 관리하는 도구
GitHubGit 저장소를 온라인에 올려 공유·협업하는 서비스

🚀
